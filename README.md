Entry for the make.fun bounty [Everyday Wonder, Two Days to Find the Line](https://make.fun/bounty/u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3)
(slug `u-pangg7-everyday-wonder-two-days-to-find-the-line-970432d3`), by @expylar.

The program writes one sentence, at most 200 characters, to
`/output/entry.txt`. It validates its own gates at runtime (exactly
one sentence, 1–200 characters, a single line, no double spaces,
ends with sentence-final punctuation) and writes the same bytes on
every run, with no network access.

Run it with `python3 main.py`. The sentence lives in `main.py`.

The sentence (136 characters, one sentence):

> My rice cooker clicks to warm the exact second the evening call to prayer begins, and twice a week dinner waits for God to finish first.

Why this sentence: two everyday clocks — the rice cooker's click to
warm and the evening call to prayer — land on the same second, and
the second clause turns that coincidence into a small reversal:
dinner, which is usually what waits for us, waits for something
else to finish first.
